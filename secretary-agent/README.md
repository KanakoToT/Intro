# 🔍📝✅ 仕事の秘書AIエージェントチーム

リサーチ担当(サトル)・企画書ドラフト担当(カエデ)・Todo管理担当(ソラ)の
3人のAIエージェントが、チャットで日々の仕事をサポートするアプリです。

## できること

- **チャットで相談** — 内容に応じて適切なメンバーが応答します
- **ウェブ検索つきのリサーチ** — サトルが実際にウェブ検索して、出典リンクつきで答えます
  (Claude APIのサーバー側ウェブ検索ツールを使用。検索の実装はこちら側に不要)
- **企画書のドラフト** — カエデが「背景 → 課題 → 提案 → 期待効果 → 進め方 → 体制/費用 →
  リスク」の構成でたたき台を書きます。書いた文書は自動保存され、Markdownでダウンロードできます
- **Todoの自動登録** — 会話に出てきたタスクをソラが拾って、期限・優先度つきでTodoに登録します。
  「あれ終わったよ」と言えば完了になります
- **調査メモの蓄積** — 検索を使った回答は出典つきで保存され、次回以降の会話でも参照されます
- **埋められない部分は [要確認]** — 数字や条件をでっちあげず、確認が必要な箇所を明示します

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | FastAPIサーバー本体(チャット・Todo・文書のAPI) |
| `agents.py` | 3人のエージェントチームの定義とClaude API呼び出し |
| `db.py` | SQLite(Todo・企画書ドラフト・調査メモ・会話履歴) |
| `static/index.html` | 画面(チャット / Todo / 文書 の3タブ) |

## セットアップ

### 1. 依存パッケージのインストール

```bash
cd secretary-agent
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. APIキーの設定

```bash
cp .env.example .env
```

`.env` を開いて `ANTHROPIC_API_KEY` を設定します
(キーは [platform.claude.com](https://platform.claude.com) で取得)。

日付の基準にするタイムゾーンは `TIMEZONE`(既定 `Asia/Tokyo`)で変えられます。

### 3. 起動

```bash
uvicorn app:app --reload
```

ブラウザで http://localhost:8000 を開きます。

## 使い方の例

| 話しかけ方 | 動くメンバー |
|---|---|
| 「競合3社のプラン価格を調べて」 | 🔍 サトル(検索して出典つきで回答 → 調査メモに保存) |
| 「来週の会議用に新サービスの企画書をたたき台で」 | 📝 カエデ(ドラフト → 「文書」タブに保存) |
| 「金曜までに部長にレビュー依頼しておく」 | ✅ ソラ(期限付きでTodo登録) |
| 「価格表の件、終わったよ」 | ✅ ソラ(該当Todoを完了に) |
| 「今日なにやればいい?」 | ✅ ソラ(未完了Todoから2〜3件に絞って提案) |

## 知っておくべきこと

- **エージェントの動きの仕組み**: 3人は1回のAPI呼び出しの中で役割分担しています
  (メンバーごとに呼び出しを分けるより速く、文脈も共有できるため)。
  Todoの登録・完了と文書の保存は、応答に混ぜた `[TODO_ADD]` `[DRAFT_START]` などの
  マーカー行をアプリ側が読み取って実行しています。マーカー行は画面には表示されません。
- **リサーチ結果は必ず確認してください**: 検索結果にもとづいて回答しますが、
  検索エンジンが拾えなかった情報や、情報源そのものが誤っている可能性があります。
  重要な意思決定に使う数字は、出典リンクを開いて裏を取ってください。
- **企画書はあくまで「たたき台」**: 社内の事情・予算・体制など、エージェントが知らない前提は
  `[要確認]` として残ります。そのまま提出できる完成物ではありません。
- **保存先はローカルのSQLite**(`secretary.db`)です。`.gitignore` 済みなので
  リポジトリにはコミットされませんが、共有PCで使う場合はご注意ください。
- **費用**: Claude API と ウェブ検索ツールの利用料がかかります。
  料金は [platform.claude.com/docs/en/pricing](https://platform.claude.com/docs/en/pricing) を確認してください。
